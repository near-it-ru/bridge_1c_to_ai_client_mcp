# Участие в разработке

Проект находится на подготовительном этапе. Обсуждения архитектуры и код принимаются через issues и pull requests.

## Рабочий процесс

1. Создайте ветку от `main`; изменения вносите через pull request.
2. Опишите проблему, итоговое поведение и выполненные проверки.
3. Для изменения протокола приложите спецификацию, модель угроз, тестовые векторы и результат проверки в 1С. Не подменяйте криптографическую экспертизу самодельными алгоритмами.
4. Не добавляйте действующие подключения, ключи, токены, реальные результаты 1С и приватные исходники.

Gitignore не удаляет уже отслеживаемые секреты. Если секрет опубликован, сначала отзовите или замените его и сообщите сопровождающему приватно; не публикуйте его повторно в issue.

## Проверки

Сейчас CI проверяет структуру репозитория, ошибки пробелов и отсутствие отслеживаемых файлов подключения. Проверка не заменяет полноценное сканирование секретов и аудит криптографии.

Локальная проверка при наличии Python 3:

```text
python .github/scripts/check_repository.py
git diff --check
```

Python используется только для проверки репозитория; он не является требованием для конечного пользователя клиента.

Go-модуль, сборка, тесты и кроссплатформенный CI будут добавлены вместе с первым кодом. Сейчас команды сборки отсутствующего клиента не предоставляются.

## Зависимости и выпуски

Фиксируйте версии зависимостей. GitHub Actions закрепляйте полным SHA. Обновления проходят PR и проверки. Выпуски с исполняемыми файлами потребуют проверки совместимости, лицензий зависимостей, подписей и воспроизводимости сборки.

Вклады предоставляются по Apache-2.0. Добавление CLA и дополнительных ограничений в этот проект не предусмотрено.
