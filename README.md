# 1C Bridge Client

Открытый локальный MCP-клиент защищённого режима 1C Bridge.

**Статус: подготовка проекта. Рабочего клиента, реализации шифрования и готовых выпусков пока нет.** Этот репозиторий не подтверждает безопасность ещё не реализованного протокола.

## Назначение

Приложение с ИИ запускает Bridge Client как локальный MCP-сервер через stdio. Клиент шифрует содержательные аргументы и расшифровывает ответы. Центральный Bridge маршрутизирует защищённые сообщения, а обработка 1С проверяет и выполняет команды.

Обычное прямое MCP-подключение остаётся отдельным режимом Bridge и не требует этой программы. HTTPS защищает канал, но при обычном подключении Bridge видит содержимое сообщений.

## Планируемая настройка

Обработка 1С сохраняет три локальных файла:

- `1c_bridge_client_config.json` — настройки подключения;
- `1c_bridge_client_key.env` — секретный ключ;
- `ИНСТРУКЦИЯ (для агента).md` — инструкция без секретов.

Эти файлы не публикуются в Git. Секрет читает клиент, его не нужно вставлять в чат агента. Формат конфигурации и ключевого файла ещё не утверждён: примеры, создающие ложную совместимость, пока не предоставляются.

Планируются переносимые сборки Go для Windows, macOS и Linux без установки Python, Node.js, Go или Docker у пользователя. Матрица поддерживаемых версий ОС и приложений появится после испытаний. Не все облачные ИИ-приложения могут запускать локальные MCP-серверы.
